# CoursePilot SJTU —— 交大“培养方案核查与智能排课”智能体

上海交通大学“交我创”智能体创新大赛（自由选题赛道）MVP 原型。

核心理念：**大模型负责自然语言偏好理解，Python 确定性算法负责毕业学分核查、先修课拓扑检查与无冲突排课求解**，并内置本地隐私脱敏与水源课程评价检索接口。

## 快速启动

```bash
# 1. 创建虚拟环境并安装依赖（推荐）
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# 2. 运行单元测试
pytest -v

# 3. 启动 Streamlit 演示界面（默认开启离线 Mock 模式，无需 API Key 即可体验）
streamlit run app.py
```

## 接入“致远一号”真实 API 与水源检索接口

复制 `.env.example` 为 `.env`，填入在赛事群获取的官方接口配置：

```ini
USE_MOCK_LLM=false
LLM_BASE_URL=https://api.zhiyuan.sjtu.edu.cn/v1
LLM_API_KEY=你的真实密钥
LLM_MODEL=qwen2.5-72b-instruct
```

## 1–2 分钟初赛录屏演示建议路径

1. **展示隐私保护**：打开左侧边栏，展开“查看脱敏前后对比预览”，展示姓名、学号、手机号和成绩分数在本地被自动剥离。
2. **展示学分缺口与先修拦截**：在 Tab 1 展示各模块学分进度条，重点指出 `CS3308 操作系统` 因未修先修课 `CS2304 计算机组成` 被自动拦截。
3. **展示智能排课与局部重排**：切到 Tab 2，输入自然语言偏好（如“16到20学分，避开早八，周三下午留空，优先补人文通识”），切换对比 Top 3 无冲突周课表网格，并演示“锁定一门课 / 排除一门课”后的毫秒级局部重排。
4. **展示水源评价与导出**：切到 Tab 3 查看候选课程的考核方式与往届建议，最后在 Tab 4 一键导出标准 `.ics` 手机日历文件。
