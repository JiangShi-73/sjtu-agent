# 微信公众号：暂停

**状态：暂停（2026-11-22）**

微信公众号抓取卡在「没有公开的文章列表接口」上，绕不过去：

| 尝试 | 结果 |
|---|---|
| 官方 API | 不存在 |
| 搜狗微信搜索 | 搜不到「芯信青年」，且需验证码 |
| 必应/百度 | 不索引公众号文章 |
| 历史消息接口 `/mp/profile_ext?action=getmsg` | `{"ret":-3,"errmsg":"no session"}`，要微信客户端会话 |
| 文章页里的 album_id | 只有分享代码，没有真实合集 id |
| WeWe RSS | 装好了、跑起来了，但扫码依赖的第三方中继 502 |
| 自建中继 `relay/` | 登录流程打通，但 weread 的公众号文章接口没摸到（需要登录态探测） |

## 现在还能用的

**按文章链接订阅**：`订阅 → 公众号文章 → 粘贴 mp.weixin.qq.com/s/...`

能抓到公众号名、标题、发布时间、摘要，进「公众号」板块。这是当前唯一稳定的路径。

## 代码保留情况

- `xinge/sources/wechat.py` —— 文章链接抓取（可用）
- `relay/` —— 自建中继（半成品，登录能通，文章列表没实现）
- WeWe RSS 装在 `%TEMP%\wewe-rss`，独立进程，不随仓库分发

## 如果以后要捡起来

1. 先让 WeWe RSS 能扫码（中继稳定出码）
2. 登录后拿 weread 的会话去探测 `/api/v2/platform/mps/{id}/articles` 对应的 weread 接口
3. 补上 `relay/server.py` 里的 `mp_articles`
