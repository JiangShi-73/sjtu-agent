# 信鸽 SJTU · 功能清单（用户版）

> 更新于 2026-11-25。这份是「你能用它做什么」，不谈技术细节。

---

## 一、它是什么

一个装在电脑上的校园信息工作台 + 一个 QQ 机器人，把 SJTU 分散在十几个站点的通知、
作业、日程、活动、邮件汇到一起，并在该提醒你的时候主动发到 QQ。

**装一次、扫一次码，之后自动跑。**

---

## 二、桌面端能做什么

### 1. 信息流（主界面）

左侧是信息源，点一下切一个板块：

| 板块 | 内容 |
|---|---|
| 全部 | 所有板块混合 |
| 存档区 | 已过期、保留 7 天 |
| Canvas | 课程公告 + 作业 |
| 活动 | 第二课堂活动（300 条） |
| 实验 | 物理实验安排 |
| 慕课 | 好大学在线的消息与作业 |
| 知途好课 | 知途的作业 |
| 学院公告 | 各学院通知（434 条） |
| 水源社区 | BBS 帖子 |
| 自定义 | 你加的 RSS |

**能做的操作：**

- 只看未读 / 全部已读 / 清理已读
- 多选批量操作
- 点标题打开原网页
- 搜索（顶部搜索框）

### 2. 日历

- 月视图，一屏看完整月
- **双击任意一天** → 弹出当天全部安排（时间段、标题、类型、地点）
- 课表 / 日程 两个开关可分别显示
- 已完成的条目显示为**删除线**，不会消失
- 蓝灰色 = 你的日程，暗红色 = 作业截止

### 3. 待办右栏

- 小月历（点哪天数哪天）
- 「Canvas / 知途 / 邮件 / 当天」四个标签
- **快速安排**输入框：直接说「明天下午3点图书馆开会」就建日程

### 4. 日程管理

四种加法：

1. 活动卡片上的 **「加入日程」** 按钮
2. 活动详情弹窗里的 **「活动加日程」/「报名截止加日程」**
3. 右栏 **快速安排** 输入框（自然语言）
4. QQ 里直接对机器人说

### 5. 订阅与登录

- **jAccount 一次扫码，所有站自动登录**：水源、好大学在线、体育、Canvas、校园活动
- 邮箱**不用输密码**，走 jAccount 直连
- 慕课课程点「自动检测」自动列出你在上的课

### 6. 问助手

内置 AI 助手，能调用所有接口。问它「这周有什么要交的」它会自己去查。

### 7. 接口管理

可以单独开关每个工具，决定问助手和机器人能调用什么。

### 8. 诊断

一键检查：浏览器是否可用、各源抓取状态、错误信息。

## 三、QQ 机器人能做什么

### 1. 指令（斜杠开头）

| 指令 | 作用 |
|---|---|
| `/信鸽` | 总览 |
| `/作业` | 待交作业 |
| `/活动` | 第二课堂活动 |
| `/活动图 2` | 发第 2 个活动的详情**截图** |
| `/慕课` | 慕课消息与作业 |
| `/邮件` | 未读邮件 |
| `/ddl` | 即将截止 |
| `/学院` | 学院公告 |
| `/日程` | 你的日程 |
| `/日历` | 日历图（`/日历 周` `/日历 日`） |
| `/搜 关键词` | 全文搜索 |
| `/水源` `/水源看` | 水源社区 |
| `/存档` | 存档区 |
| `/刷新` | 立即抓全部 |
| `/清理` | 清理已读 |
| `/提醒` | 看提醒绑定状态 |

回复数字可以直接看某条的详情。

### 2. 自然语言（不用记指令）

**建日程：**
```
明天下午3点图书馆开会
下周一上午9点上机实验，东上院308
11月30日中午12点半 体检
后天下午3点三刻 东中院2-106 上机
```

支持「点半 / 点一刻 / 点三刻 / 点整」，也认不带「在」的楼号。

**查东西：**
```
最近有什么作业
今天要交的作业
这周有什么活动
明天有什么安排
今天有课吗
有新的邮件吗
```

**按属性查活动：**
```
有哪些有劳动学时的活动
有新时代讲座的活动吗
最近有什么活动
```

> 「素拓分数」查不了——平台只提供「劳动学时」和「新时代讲座」两个属性。

**改提醒设置：**
```
提醒提前一小时
作业改成提前两天提醒
每天晚上十点以后别推
每小时最多推 5 条
把提醒关掉
现在提醒设置是什么
```

**复杂问题（走 AI，慢 25–60 秒）：**
```
选课什么时候开始
最近食堂怎么样
```

## 四、主动推送（不用问，到点自动发）

| 类型 | 什么时候推 | 长什么样 |
|---|---|---|
| **日程提醒** | 开始前 60 分钟 | ⏰ 图书馆开会 / 15:00 图书馆 |
| **作业提醒** | 截止前 24 小时 + 2 小时 | 📚 头歌作业 / 11-25 17:59 Canvas |
| **邮件提醒** | 新邮件到达（30 分钟巡检） | 📧 新邮件 · 发件人 / 主题 |
| **每日早报** | 每天 07:30 | ☀️ 今天 3 件事 + 逐条列出 |
| **公告汇总** | 每晚 20:00（有新增才推） | 学院公告 N 条 + 标题 |
| **新活动** | 发现新活动 | **图片**（活动清单，带属性标签）+ 文字 |
| **登录过期** | jAccount 失效 | ⚠️ 带「点哪里重新登录」的指引 |
| **抓取失败** | 某源连续 3 轮失败 | ⚠️ 带错误原因 |

**不会推的：**
- 课表/上课提醒（你关掉了）
- RSS 未配置这类「没配置」的情况（不算故障）
- 过期超过 24 小时的旧提醒（直接丢弃）
- 没有新公告的时候

## 五、提醒怎么调

**在 App 里调**：机器人弹窗 → 提醒区域

| 项 | 默认值 | 说明 |
|---|---|---|
| Bot 主动推送 | 开 | 关掉就不发 QQ 了 |
| App 内日程刷新 | 开 | 关掉后 App 不自动刷新（但仍可手动） |
| 日程提前 | 60 分钟 | |
| 作业提前 | 24 小时 | |
| 作业再提醒 | 2 小时 | 填 0 = 不要第二次 |
| 每小时最多 | 3 条 | 超出排队 |
| 静默开始/结束 | 01:00–07:30 | 这段时间不推 |

**在 QQ 里调**：见上面「改提醒设置」。

## 七、已知限制

| 限制 | 说明 |
|---|---|
| 第二课堂**素拓分数** | 平台没有这个数据 |
| Canvas 课程事件 | 你账号里没有这类事件，接口返回空 |
| 群聊推送 | 只支持私聊，群聊需要群内开「机器人主动发言」 |
| 桌面快捷方式图标 | exe 图标要重新打包才能换 |
| 好大学在线登录 | 经常掉，掉了会给你发告警，点订阅里重新登录 |

## 八、一分钟上手

1. 打开信鸽 → 扫码登录 jAccount
2. 左栏点「全部」看信息流
3. 日历双击某天看当天安排
4. QQ 里对机器人说「明天下午3点图书馆开会」
5. 等 07:30 的早报
