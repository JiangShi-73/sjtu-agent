# 信鸽 · 提醒规则（v3 最终版）

> 已按用户确认执行。这份是施工依据，不再是草案。

## 1. 推送对象：在 App 里设置

「机器人」弹窗新增「提醒推送给谁」：

- 留空 → 自动绑定第一个给机器人发私聊的人
- 手动填 → 以手动为准（自动绑定不再覆盖）
- 解绑 → 清空

存储在后端 `settings` 表：`reminder_umo` / `reminder_umo_at` / `reminder_umo_source`。

接口：
```
GET  /api/v1/bot/reminders/target
POST /api/v1/bot/reminders/target   {"umo":"..."}   空字符串 = 解绑
POST /api/v1/bot/reminders/bind     {"umo":"...","sender_id":"...","nickname":"..."}
```

## 2. 推送什么

### 2.1 日程（events 表全部）

| 类型 | 提前 |
|---|---|
| 有 start_time | 开始前 60 分钟 |
| 无 start_time（全天） | 当天 08:30 |

包含：手动新建的、从活动「加入日程」生成的、从作业加进日程的。

### 2.2 作业（items 表四个板块）

| board | 来源 | 提前 |
|---|---|---|
| course | Canvas | 24h + 2h |
| mooc | 好大学在线 | 24h + 2h |
| zhitu | 知途好课 | 24h + 2h |
| lab | 物理实验 | 24h + 2h |

### 2.3 邮件

- 每 30 分钟检查一次
- 新邮件：发件人 + 主题
- 每次最多 3 条，超出合并
- 去重表 `mail_seen(mid, seen_at)`

### 2.4 不推送

- 课表/上课提醒（用户明确不要）
- 学院公告、水源社区、RSS（未要求）

## 3. 推送格式

日程：
```
⏰ 图书馆开会
15:00 图书馆
```

作业：
```
📚 2 天后截止 · 第五章作业
12-02 17:59 · Canvas
```

邮件：
```
📧 新邮件 · 某老师
关于期末考试的安排
```

早间汇总（07:30，有 2 条以上时合并）：
```
☀️ 今天 3 件事 · 11/25
09:30 电磁场（东上院308）
15:00 图书馆开会
17:59 头歌作业截止
```

## 4. 节流与静默

- 静默时段 **01:00–07:30**：不推，顺延到 07:30（用户 2026-11-24 要求从 23:00 改为 01:00）
- 每用户 **每小时最多 3 条**，超出合并
- 过期 **>24h** 丢弃；**<24h** 合并成一条补推
- 发送失败重试 3 次，仍失败标 `failed`
