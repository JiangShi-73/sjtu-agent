# PathFinder SJTU

首页在「截止事项」中汇总日程与个人待办。个人背景支持选择交大学院和专业，用于筛选已收录的院系通知和核对申请条件。学院专业选项来自交大培养计划和招生目录，未收录的项目可手动填写。访客数据保存在浏览器，登录后使用账号独立的服务器存储。

[开发日志](CHANGELOG.md)记录功能更新、部署进展和待验证的工作。

## 本地开发

使用 Node.js 24 LTS，在项目目录运行

```powershell
npm.cmd run dev
```

打开 [本地开发地址](http://127.0.0.1:4173/)。使用 [固定日期演示](http://127.0.0.1:4173/?demo=1) 可以重放 2026 年 11 月 19 日的样例，数据与正常模式分开保存。

在固定日期演示中，可填入第一个示例背景并打开「先进计算夏令营」核验条件。生成申请计划后，准备任务会出现在首页的「未来计划」中，确认后也可下载日历。

正常模式使用 `web/public-data.js` 中人工核对的公告。更新时保留稳定的记录 ID 和来源网址，并同步更新核对日期。只有公告明确给出的截止日期进入日程。有具体通知截止时间时，按北京时间判断是否已过期。复杂资格保留为手动核对。固定日期演示单独使用 `fixtures/mvp-demo.json`。

学院公告来源见 `scripts/college-sources.json`。运行 `python -X utf8 scripts/update-college-notices.py` 可从公开网页更新 `web/college-bulletins.js`，也可以在命令末尾指定学院 ID。来源暂时无法读取时保留上一次已收录的结果。更新后运行 `npm run build` 重新生成公开网站。收录内容只包含标题、发布日期和原文链接。

## 构建与目录

```powershell
npm.cmd run build
```

构建产物在 `dist/`。静态服务器支持访客模式，注册、登录和账号存储需要同时运行 Node 服务。本地开发命令同时启动页面和账号接口，数据库默认位于项目的 `.pathfinder-data/`。

「日程导视」的智能体需要登录，并由服务端环境变量 `PATHFINDER_AI_API_KEY` 启用。它可使用站点收录的机会、校历和学院通知，以及与问题相关的交大原文。发送消息时，后端会向交大模型提供对话、院系专业、未完成待办和申请安排。对话只保留在当前页面会话中。生成的待办和申请计划可以手动保存，也可以在发送前勾选自动保存。[交大模型 API 文档](https://apps.hpc.sjtu.edu.cn/posts/claw-guide-sjtu-api)

| 目录 | 内容 |
| --- | --- |
| `web/` | Web 页面和浏览器代码。`domain.js` 存放独立业务规则，`repository.js` 是数据访问入口 |
| `fixtures/` | 虚构机会和用户样例 |
| `docs/` | 首版需求、页面结构、任务与部署说明 |

学校云服务器配置见 [Ubuntu 部署说明](docs/Ubuntu-部署.md)。
